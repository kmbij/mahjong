# 🀄️ 雀友懲罰器 (Mahjong Penalty Generator)

> 「這是一款既可以認真打牌，也可以胡鬧嘻笑的抽籤網站！」

## 靈感來源
靈感來自抖音平台，我發現原來打麻將是可以充滿歡笑聲、甚至是各種荒謬的場面，而不是死板地坐在牌桌上盯著牌局。這個網站最適合一群「沒錢（或輸不起大錢）」但想把牌局氣氛炒到最高點的朋友們了！

---

## 主要功能特色

- **實時連線房間**：輸入 4 碼房號即可輕鬆開房，支援多位好友同步連線。
- **雙模式懲罰抽籤**：
  - **官方固定庫**：內建豐富好玩的觸發條件與爆笑懲罰。
  - **自訂同步區**：房主可自行輸入專屬的「觸發條件」與「懲罰動作」，即時同步給全房間！
- **即時麻將計分板**：
  - 開局前可自訂**底分**與**一台多少分**。
  - 支援「自摸」與「放銃」自動計算輸贏金額，即時更新積分榜。
  - 附有 **復原上一局** 功能，手殘按錯也能秒救援！
- **個人 Emoji 代表**：玩家可自訂專屬 Emoji 與暱稱，讓戰績排行榜更有個人特色。
- **PWA 支援**：支援 iOS (Safari) 與 Android (Chrome)「加入主畫面」，點開就像App一樣方便！

---

## 技術堆疊 (Tech Stack)
- **Frontend**: HTML5, CSS3, JavaScript
- **Database**: Firebase Realtime Database (即時同步房間狀態、玩家名單與積分)
- **Hosting**: Vercel
